<p align="center">
  <strong>Taxonomic hierarchy distances and lineage analysis in R, Python, and Julia.</strong><br>
  <a href="https://taxodist.github.io/">Documentation</a> ·
  <a href="https://3w6g1b-rodrigo-villa.shinyapps.io/taxodist_app/">Interactive app</a>
</p>

`taxodist` retrieves ordered lineages from [The Taxonomicon](http://taxonomicon.taxonomy.nl), compares taxa through the depth of their most recent common ancestor, and integrates the resulting distances with multivariate analysis workflows.

| Language | Package | Source code |
|---|---|---|
| R | [CRAN](https://cran.r-project.org/package=taxodist) | [rodrigosqrt3/taxodist](https://github.com/rodrigosqrt3/taxodist) |
| Python | [PyPI](https://pypi.org/project/taxodist/) | [rodrigosqrt3/taxodist-py](https://github.com/rodrigosqrt3/taxodist-py) |
| Julia | [JuliaHub](https://platform.juliahub.com/ui/Packages/General/Taxodist/) | [rodrigosqrt3/Taxodist.jl](https://github.com/rodrigosqrt3/Taxodist.jl) |

Lineage data originate from **The Taxonomicon**, based on *Systema Naturae 2000* by S. J. Brands. Published analyses should cite both the software and the underlying classification source.
